# 3B

Данный проект — это как модуль или небольшой обвесик, как я люблю называть, для VPN‑сервисов таких как **3x-ui** и других.

**В чем суть?** Суть в том, чтобы убрать надобность клиентам VPN ставить запрет на свои устройства, а вместо этого использовать блага обхода блокировок просто подключившись к серверу.

В данном случае мы имеем скрипт, который пропускает весь трафик через себя и отдаёт уже клиентам, которые подключены к нашему VPN.

В моём случае стратегия работает следующим образом:

```
client -> inbound (3x-ui, VLESS+Reality+XHttp)
       -> outbound (freedom)
       -> queue table
       -> nfqws
       -> internet
```

Чуть длинновато, но суть раскрывает.

---

## Как использовать

В принципе, вы можете просто от лица root на своём сервере запустить данное приложение — и всё, уже будет работать наша программка:

```bash
sudo ./start.sh
```

---

## Добавление стратегий

Для добавления стратегий можно воспользоваться примером уже готовой стратегии обхода YouTube‑блокировок.

Таким же образом вы создаёте файл `name.conf` в папке **strategies** и пишете туда свои конфиги.

Если используются списки хостов — для них есть специальная папка **hostlists**.

---

## Использование как сервис

Можете использовать данное решение как сервис на своём сервере — у меня оно так и работает.
